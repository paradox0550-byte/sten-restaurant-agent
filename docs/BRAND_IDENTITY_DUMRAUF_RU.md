# DUMRAUF — бренд-платформа

**Статус:** утверждённое направление бренда; юридическая проверка товарных знаков и доменов не завершена.

- **Master brand:** DUMRAUF

- **Технологическая платформа / архитектурное направление:** DUMRAUF Systems

- **Авторская подпись:** by Dumrauf

## Позиционирование

DUMRAUF — авторский технологический бренд управленческих систем.  
DUMRAUF Intelligence помогает руководителям видеть фактическое состояние бизнеса, проверять данные, рассчитывать показатели и принимать обоснованные решения.

Начальная специализация продукта — ресторанный бизнес и HoReCa. Архитектура бренда не должна ограничивать дальнейшее развитие другими отраслями.

## Принципы бренда

1. Data over decoration — данные важнее визуального шума.
2. No fake certainty — не создавать ложную уверенность.
3. Calculation before interpretation — сначала расчёт, затем вывод.
4. No source = no fact — без источника нет факта.
5. Preserve the system — ребрендинг не должен разрушать архитектуру, данные, функции и интеграционные контракты.

## Правила миграции

- STEN считается прежним публичным названием продукта.
- Новое публичное имя — DUMRAUF Intelligence.

- Исторические документы, записи релизов и юридические положения не переписывать механической заменой.
- Сохранить историю происхождения проекта и авторство.
