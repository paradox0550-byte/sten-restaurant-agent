# DUMRAUF Intelligence 0.5.1 — руководство пользователя

## 1. Что такое DUMRAUF Intelligence

DUMRAUF Intelligence — система управленческого анализа и поддержки решений для бизнеса. Начальная специализация — ресторанный бизнес и HoReCa.

Система помогает разбирать экономику, операции, работу команды, меню, сервис и риски; проверять данные; выполнять расчёты; формировать управленческие решения и контролировать результат.

DUMRAUF не заменяет POS, бухгалтерскую систему, юриста, технолога, специалиста по охране труда или ответственность руководителя. Наличие файлов знаний в ChatGPT Project само по себе не подключает программное ядро, API, iiko, банк или постоянную серверную память.

## 2. Варианты поставки

**ChatGPT Project — пользовательский комплект знаний.** Девять Markdown-файлов загружаются в Sources, а отдельный файл инструкций вставляется в поле Project instructions. Это простой способ начать работу без установки программ.

**ChatGPT plugin package — пакет адаптера.** Воспроизводимый архив собирается из исходников providers/chatgpt/plugin-source/ командой npm run build:chatgpt-plugin. Это технический пакет для поддерживаемого процесса установки/обновления плагина, а не архив для загрузки в Sources проекта.

**Source package — исходный код.** Полный репозиторий содержит программное ядро, тесты, навыки, методики и документацию. Он не является готовым развёрнутым сервером.

## 3. Подключение через ChatGPT Project

1. Создайте новый ChatGPT Project.
2. Откройте настройки проекта и найдите поле Project instructions.
3. Скопируйте полный текст из providers/chatgpt/project-instructions-ru.md и вставьте его в это поле.
4. Загрузите все девять файлов из providers/chatgpt/knowledge-pack/ в Sources:
   - 01-core-rules-and-evidence.md
   - 02-restaurant-management-and-shift.md
   - 03-guest-service-and-recovery.md
   - 04-food-safety-haccp-marking.md
   - 05-iiko-stock-and-calculator-audit.md
   - 06-menu-engineering-and-kitchen-workforce.md
   - 07-finance-payroll-and-labor.md
   - 08-operational-audit-and-checklists.md
   - 09-stage-11-scope-and-validation.md
5. Проверьте, что все девять файлов видны в Sources, а инструкции сохранены отдельно в Project instructions.
6. Начните новый чат внутри проекта и отправьте: «Ты работаешь как DUMRAUF Intelligence. Подтверди, какие инструкции и файлы доступны. Не утверждай, что подключён к внешним системам или серверной памяти. Помоги решить мою текущую управленческую задачу».

Подробная схема находится в CONNECTION_ALGORITHM_RU.md. Лимиты файлов и функции Projects зависят от тарифа и текущего интерфейса ChatGPT; ориентируйтесь на ограничения, показанные в вашем аккаунте.

## 4. Работа с несколькими ресторанами

Один руководитель может вести несколько ресторанов в одном Project, если имеет право доступа ко всем этим данным и может надёжно разделять контекст. Для независимых компаний, разных владельцев или разных прав доступа используйте отдельные Projects.

При сравнении DUMRAUF сначала показывает результаты каждого объекта отдельно. Объединение показателей допустимо только при сопоставимых периодах, валютах, определениях и периметрах. Финансовые, кадровые, гостевые и операционные факты нельзя переносить из одного ресторана в другой.

## 5. Основные правила анализа

- **Нет источника — нет факта.**
- **Отсутствует — не значит ноль.**
- Не смешивать разные рестораны, периоды, подразделения и валюты без объяснения.
- Не выдавать корреляцию за причину.
- Не скрывать конфликтующие данные.
- Не называть гипотезу подтверждённой причиной.
- Не считать задачу выполненной без подтверждения результата.

В ответах разделяйте подтверждённые сведения, расчёты, интерпретации, гипотезы, рекомендации и неизвестное.

## 6. Примеры задач

**Финансы**
- «Разбери P&L за октябрь. Покажи формулы, подтверждённые отклонения и недостающие данные».
- «Сопоставь выручку POS, банковские поступления и возвраты. Не подгоняй суммы».

**Персонал**
- «Проверь график смен и покажи часы, стоимость труда и возможные перегрузки».
- «Рассчитай потребность кухни по участкам и временным интервалам. Если нет норм времени, обозначь ограничение».

**Меню**
- «Проведи Menu Engineering. Проверь полноту продаж, техкарт, себестоимости и маржинального вклада».
- «Покажи позиции, по которым нельзя сделать вывод из-за отсутствующих данных».

**Операции и сервис**
- «Подготовь план открытия смены с контрольными точками».
- «Разбери жалобы гостей и предложи действия с проверкой результата».
- «Составь план корректирующих действий: проблема, доказательство, ответственный, срок и критерий проверки».

## 7. Проверка качества ответа

Для существенного управленческого решения попросите DUMRAUF показать исходные данные и период; источники и ограничения; формулы и расчёты; подтверждённые факты отдельно от гипотез; недостающие данные; действия, ответственных, сроки и критерии проверки — если они известны.

Не передавайте в Project персональные данные, банковские реквизиты, пароли, токены или документы, которые вы не вправе загружать.

## 8. Ограничения текущей версии

Репозиторий содержит рабочее программное ядро и адаптеры, но не является сам по себе развёрнутым production-сервисом. Внешние подключения, постоянное хранилище памяти, авторизация и эксплуатационная инфраструктура требуют отдельной настройки и проверки. Наличие навыка или методики не доказывает её экспертную валидацию.

Юридические, налоговые, трудовые и санитарные выводы требуют актуального официального источника и проверки профильным специалистом. Критические решения и внешние действия остаются за уполномоченным человеком.
