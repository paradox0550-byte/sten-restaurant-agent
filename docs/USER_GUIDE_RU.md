# STEN 0.5.0 — руководство пользователя

## 1. Что такое STEN

STEN — экспертная система управленческой поддержки ресторанного бизнеса. Она помогает руководителю разбирать экономику, операции, работу команды, меню, сервис и риски; находить подтверждённые отклонения; формировать управленческие решения и проверять их результат.

STEN не заменяет POS, бухгалтерскую систему, учётную политику, юриста, технолога, специалиста по охране труда или ответственность руководителя.

## 2. Что входит в пользовательский комплект

В Dropbox размещается один согласованный выпуск: девять файлов базы знаний, отдельные инструкции для ChatGPT Project, руководство пользователя, алгоритм подключения и заметка о версии и составе комплекта.

Пользовательский архив содержит только материалы, предназначенные для подключения к Project. Внутренние исследовательские реестры, служебные метаданные и исходные материалы в него не включаются.

## 3. Как начать

1. Скачайте последний архив из Dropbox: **STEN Restaurant Agent → 05. Обновления и версии**.
2. Распакуйте его.
3. Создайте ChatGPT Project.
4. Вставьте файл инструкций в отдельное поле Project instructions.
5. Загрузите девять файлов из папки knowledge-pack.
6. Начните чат внутри проекта со стартового сообщения из инструкции подключения.

Подробная последовательность находится в документе **Инструкция подключения к ChatGPT Project**.

## 4. Работа с несколькими ресторанами

Один руководитель может вести несколько ресторанов в одном Project, если у него есть право доступа ко всем этим данным и их можно надёжно разделять по контексту.

Для независимых компаний, разных владельцев, разных прав доступа или повышенных требований конфиденциальности используйте отдельные Projects.

При сравнении нескольких ресторанов STEN сначала показывает результаты каждого объекта отдельно. Объединение показателей допустимо только при сопоставимых периодах, валютах, определениях и периметрах.

## 5. Основные правила анализа

- **Нет источника — нет факта.**
- **Отсутствует — не значит ноль.**
- Не смешивать разные рестораны, периоды, подразделения и валюты без явного объяснения.
- Не выдавать корреляцию за причину.
- Не скрывать конфликтующие данные.
- Не называть гипотезу подтверждённой причиной.
- Не считать задачу выполненной без подтверждения результата.

В ответах разделяйте подтверждённые сведения, расчёты, интерпретации, гипотезы, рекомендации и неизвестное.

## 6. Примеры задач

**Финансы**
- «Разбери P&L за октябрь. Покажи формулы, подтверждённые отклонения и недостающие данные».
- «Сопоставь выручку POS, банковские поступления и возвраты. Не подгоняй суммы».

**Персонал**
- «Проверь график смен и покажи часы, стоимость труда и возможные перегрузки».
- «Рассчитай потребность кухни по участкам и временным интервалам. Если нет норм времени, обозначь ограничение».

**Меню**
- «Проведи Menu Engineering. Проверь полноту продаж, техкарт, себестоимости и маржинального вклада».
- «Покажи позиции, по которым нельзя сделать вывод из-за отсутствующих данных».

**Операции и сервис**
- «Подготовь план открытия смены с контрольными точками».
- «Разбери жалобы гостей и предложи действия с проверкой результата».
- «Составь план корректирующих действий: проблема, доказательство, ответственный, срок и критерий проверки».

## 7. Как выглядит качественный результат

Для существенной управленческой задачи ожидайте:
1. Краткий вывод.
2. Подтверждённые данные и их источники.
3. Расчёты с формулами и единицами измерения.
4. Пробелы, ограничения и противоречия.
5. Гипотезы, отдельно от фактов.
6. Рекомендации, ответственные роли, сроки и способ проверки.

Если данных недостаточно, STEN должен назвать, чего именно не хватает, а не заполнять пробелы предположениями.

## 8. Ограничения текущего режима Project

Подключение файлов к ChatGPT Project предоставляет модели контекст документов и инструкций. Оно не означает, что программные модули репозитория запущены или что система подключена к POS/iiko, банку, складу, CRM, API либо серверной памяти.

Не считайте, что файл автоматически обновился после изменения в Dropbox. Для обновления скачайте новую версию и замените материалы в Project.

## 9. Конфиденциальность и безопасность

Перед загрузкой проверьте право передавать данные выбранной AI-платформе. По возможности обезличивайте отчёты и удаляйте сведения, не нужные для задачи. Не загружайте пароли, токены, данные карт и документы, к которым у вас нет законного доступа.

Для строгого разделения разных компаний используйте отдельные Projects и не переносите факты одного ресторана в контекст другого.

## 10. Обновления

Единственный источник пользовательских файлов — актуальная папка релиза STEN в Dropbox. Сверяйте версию архива, руководства и состава комплекта. При обновлении заменяйте комплект целиком, а не отдельные случайные файлы.
