## Российская методика программы «Тайный гость» (20.11.2026)
Тайный гость — диагностический инструмент, не самостоятельное доказательство дисциплинарного проступка и не автоматическое основание увольнения.
**Правовые рамки:** ТК РФ ст. 86–88 и № 152-ФЗ — если отчёт позволяет идентифицировать сотрудника, определить цель, основание, срок, доступ и защиту данных. Не использовать исключительно автоматизированный результат для решений, затрагивающих работника. Скрытые аудио/видеозаписи не включать в методику без отдельного заключения юриста.
**Цикл:** утвердить формат/маршрут/критерии → задать проверяемый сценарий → зафиксировать загрузку, стоп-лист и сбои → отделить факт от мнения → приложить доказательства к отрицательным пунктам → дать сотруднику возможность объяснить контекст → агрегировать результаты для обучения → повторить визит.
**PASS:** визит сопоставим; критерии известны; факты и мнения разделены; данные защищены; CAPA перепроверена.
**FAIL:** субъективное впечатление как факт; скрытая запись без правового анализа; публичный персональный рейтинг; взыскание по баллу без процедуры ТК РФ ст. 192–193.
