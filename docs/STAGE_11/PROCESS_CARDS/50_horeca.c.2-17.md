## Российская методика учёта основных средств и ТМЦ (20.11.2026)
**Правовая рамка:** № 402-ФЗ; ФСБУ 6/2020 «Основные средства»; ФСБУ 5/2019 «Запасы»; ФСБУ 28/2023 «Инвентаризация» (обязателен с 01.04.2025); ФСБУ 26/2020 «Капитальные вложения»; ФСБУ 25/2018 — если актив получен по аренде/лизингу.
**Процесс:** определить объект и единицу учёта → классифицировать как ОС/запас/капвложение/арендный актив по учётной политике → собрать первичку и дату готовности/получения → установить первоначальную стоимость и компонентный состав → присвоить инвентарный ID/место/ответственного → начислять амортизацию/списывать по применимому стандарту → проводить инвентаризацию и перемещения → документировать выбытие.
Не применять один денежный порог для всех организаций без проверки учётной политики и действующих стандартов; налоговый и бухгалтерский учёт могут различаться.
**PASS:** классификация и оценка обоснованы; объект физически идентифицируем; местоположение/ответственный актуальны; перемещение и выбытие документированы.
**FAIL:** ОС списано только по факту оплаты; ТМЦ учтено как ОС без основания; аренда/лизинг не отражены по применимому стандарту; объект отсутствует при инвентаризации.
