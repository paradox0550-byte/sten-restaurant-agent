# Карточка 36. Сверка взаиморасчетов с контрагентами

**ID процесса:** `horeca.c.2-3`
**Исходный реестр:** [77 индивидуальных карточек](../STAGE_11_77_INDIVIDUAL_EVIDENCE_CARDS_RU.md)
**Статус:** C — не допущен; доказательная проверка не завершена.

- **Доказательный домен:** contracts.
- **Индивидуальный маршрут источников:** E16, E20, E22. Это начальный список релевантных источников; каждый тезис нужно сопоставить с точным положением документа.
- **Что должно быть доказано именно для этого процесса:** Подписанный договор и приложения; полномочия; версия; спецификация; цена/налоги; SLA; изменение; возврат/претензия; сроки уведомлений; платежная сверка.
- **Приёмочные испытания:** Проверить изменение цены, частичное исполнение, спор по качеству, отзыв партии, просрочку и истечение срока.
- **Обязательный результат карточки:** актуальная процедура и версия; входы/выходы; роли RACI; полномочия; записи и источники; исключения; риск ошибки; критерий pass/fail; ответственный за проверку; дата следующего пересмотра.
- **Формулы:** если процесс содержит расчёт — воспроизвести на независимом тестовом примере; если не содержит — зафиксировать «не применяется». Никакие проценты, сроки, температурные пределы или правовые пороги не добавлять без первичного источника и условий применимости.
- **Критерий допуска:** индивидуальный шлюз 1–7 выше + подтверждение владельца процесса и независимого проверяющего.
- **Текущий статус:** C — индивидуальная доказательная проверка не завершена; к автоматическим решениям и обязательным SOP не допущен.
