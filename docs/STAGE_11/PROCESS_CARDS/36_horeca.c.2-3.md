## Российская методика сверки взаиморасчётов (20.11.2026)
**Правовая рамка:** ГК РФ ст. 309–310 и соответствующий договор; № 402-ФЗ ст. 9–10 — первичные документы и регистры. Акт сверки — инструмент сопоставления данных сторон, сам по себе не заменяет накладные/акты/платежи и не доказывает автоматически каждую операцию.
**Процесс:** выбрать контрагента/договор/период → выгрузить обороты обеих сторон → сопоставить документ-к-документу (дата, номер, сумма, НДС, валюта, назначение) → учесть платежи, возвраты, корректировки, зачёты и кредит-ноты → составить список расхождений → запросить подтверждающие документы → согласовать акт сверки → оформить корректировки только по первичным основаниям.
**PASS:** совпадает начальный остаток и движения; разница объяснена документами; подписант уполномочен; спорные позиции открыты.
**FAIL:** закрытие расхождения только актом без первички; зачёт без основания; документы разных юрлиц/периодов; подписант не уполномочен.
