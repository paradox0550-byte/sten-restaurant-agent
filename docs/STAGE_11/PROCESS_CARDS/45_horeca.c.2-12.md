## Российская методика периодической отчётности по персоналу (20.11.2026)
**Правовая рамка:** ТК РФ и № 27-ФЗ; отчётность работодателя в СФР (форма ЕФС-1) и ФНС (в частности 6-НДФЛ, расчёт по страховым взносам — когда применимо). Не путать кадровое событие, персонифицированные сведения и налоговую отчётность.
- По официальному разъяснению СФР подраздел 1.1 ЕФС-1 при приёме/увольнении и отдельных кадровых событиях направляется не позднее следующего рабочего дня после подтверждающего документа/решения; для иных разделов формы действуют свои сроки.
- Состав и сроки формы проверять по конкретному подразделу и виду события на дату подачи.
**Процесс:** реестр работников и кадровых событий → сверка договоров/приказов/табеля/начислений → определить формы и сроки → проверить персональные данные/СНИЛС/идентификаторы → сформировать отчёт → проверить контрольные соотношения → отправить → сохранить квитанцию → исправить ошибки.
**PASS:** все события попали в нужный отчёт; срок рассчитан по типу события; отчёт принят; исправления прослеживаются.
**FAIL:** приём/увольнение пропущены; перепутан срок для разных подразделов ЕФС-1; отчёт отправлен, но не принят; данные расходятся с кадровыми документами.
