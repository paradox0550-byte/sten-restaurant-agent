# Единый источник STEN AI для ChatGPT

**Статус:** целевая схема принята; миграция текущего плагина в репозиторий начата в ветке architecture/single-source-of-truth.

## Решение

Единственный источник истины — репозиторий paradox0550-byte/sten-restaurant-agent.

- Методология, исследования, знания, доказательная база, общие навыки, вычислительные модули, тесты и критерии качества поддерживаются в корне репозитория.
- Специфичные для ChatGPT инструкции и формат плагина хранятся в providers/chatgpt/.
- Текущие файлы исходного плагина перенесены в providers/chatgpt/plugin-source/. После миграции это исходники сборки, а не независимая ветка знаний.
- Установленный ChatGPT-плагин — только опубликованный/установленный артефакт. Редактировать его вручную запрещено: сначала изменение в GitHub, затем проверка, сборка и обновление плагина из артефакта.
- Другие платформы получают собственные адаптеры из того же ядра. Они не создают отдельные копии методологии.

## Где что является каноническим

| Область | Каноническое расположение |
|---|---|
| Идентичность и общие правила поведения | assistant/ |
| Методология, отраслевые знания и источники | knowledge/ |
| Общие повторно используемые навыки | skills/ |
| Детерминированные расчёты и исполняемая логика | src/, tools/ |
| Проверки и регрессионные сценарии | tests/, evals/ |
| ChatGPT-специфичные инструкции и API-контракт | providers/chatgpt/ |
| Исходники пакета ChatGPT-плагина | providers/chatgpt/plugin-source/ |
| Компактная база знаний ChatGPT Project | providers/chatgpt/knowledge-pack/ |

Файлы в providers/chatgpt/plugin-source/skills/sten-core-knowledge/references/ на этапе миграции сохранены без потери содержимого. Их содержимое должно быть сверено с knowledge-pack/; при совпадении в финальной сборке должен оставаться один канонический текст, а не две независимо редактируемые версии.

## Обязательный процесс изменения

1. Изменить канонический файл в этом репозитории.
2. Если изменение относится к общему ядру — обновить общие навыки/знания и соответствующие тесты.
3. Если изменение относится только к интерфейсу ChatGPT — обновить адаптер в providers/chatgpt/.
4. Запустить тесты, проверку Evidence Registry, проверку манифеста и сборку ChatGPT-пакета.
5. Проверить полученный архив и его исходную ревизию.
6. Только после успешной проверки обновить установленный плагин из архива этой ревизии.
7. Зафиксировать в релизе плагина соответствующий commit SHA. Не обновлять плагин из вручную собранной или изменённой копии.

## Запреты

- Не редактировать навыки и знания непосредственно в Plugin Creator.
- Не поддерживать параллельные версии одних и тех же правил в разных местах.
- Не считать наличие файла доказательством проверенного качества.
- Не включать клиентские документы, банковские выписки, персональные данные, токены и секреты в пакет.
- Не заявлять о доступе к GitHub, iiko, банку, ОФД, API, постоянной памяти или файловому хранилищу, если соответствующий инструмент реально не подключён.
- Не смешивать исходный репозиторий, компактный Project knowledge pack и установленный runtime-плагин: это разные уровни одного продукта.

## Текущее состояние миграции

- Исходный плагин версии 0.4.5 остаётся приватным и неизменённым до завершения сверки.
- Текстовые исходники плагина, каталоги навыков, инструкции и SVG-элементы перенесены в providers/chatgpt/plugin-source/.
- В старом пакете есть расхождение: метаданные и каталог заявляют 21 навык, фактически присутствуют 27 файлов SKILL.md. Это должно быть исправлено в исходнике до следующей сборки.
- В репозитории уже есть отдельный ChatGPT Project knowledge pack из 9 файлов. Его нельзя незаметно заменить содержимым старого плагина.
- Перенос исходников не означает, что установленный плагин уже синхронизирован. До обновления из проверенного архива он остаётся старым артефактом.

## Критерий завершения

Единый источник считается технически внедрённым, когда все необходимые компоненты текущего плагина хранятся в репозитории; повторяемая сборка формирует плагин без ручного копирования; CI проверяет структуру, количество навыков, ссылки на исходники и тесты; установленный плагин обновлён из сборки конкретного commit SHA; дальнейшее изменение плагина вне репозитория исключено процессом выпуска.
