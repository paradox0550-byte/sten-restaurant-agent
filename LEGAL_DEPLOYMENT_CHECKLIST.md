## Важное ограничение публичного GitHub

По условиям GitHub публичный репозиторий доступен для просмотра и fork другими пользователями GitHub. Индивидуальная лицензия STEN не отменяет права, предоставленные платформой. Поэтому при сохранении публичного репозитория нельзя обещать абсолютный запрет на создание копий/fork внутри GitHub. Можно закрепить запрет на перепродажу и дальнейшее распространение изменённых версий в пределах, допускаемых правами GitHub и законом.

Если принципиально необходимо исключить fork через GitHub, репозиторий придётся сделать приватным. Это изменит условия публичного пилота.
